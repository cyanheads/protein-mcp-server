# 0.8.4 — 2026-09-22

## Fixed

- **`protein_find_similar` `by: "structure"`** — a multichain structure's Foldseek job now exposes every chain's query instead of always reading query 0: a new `query` input (0-based, default 0) selects one, the response reports `query`/`queryCount`, and an out-of-range index is rejected with a typed `query_out_of_range` error rather than the provider's silent empty result (#63).
- **`protein_find_similar` `by: "structure"`** — hits are now ranked by `score` across every searched database before `start`/`limit` paging, instead of the previous per-database block order that could bury a stronger hit from a later database behind weaker hits from the first (#64).
- **`FoldseekService.parseTarget`** — PDB target headers in assembly form (`1crn-assembly1.cif.gz_A`) now resolve the chain letter; previously only bare (`1abc_A`) headers parsed.
