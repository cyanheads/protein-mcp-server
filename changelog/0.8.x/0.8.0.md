# 0.8.0 — 2026-09-09

## Added

- **`protein_find_similar`** (`by: "structure"`) reports `totalCount`/`start`/`nextStart` on a completed Foldseek search, and a complete response now carries `ticketId` so a finished job can be re-paged with a new `start` instead of resubmitted ([#53](https://github.com/cyanheads/protein-mcp-server/issues/53)).

## Changed

- **`protein_find_similar`** rejects an input field the selected `by` mode can't consume — `sequence`/`max_evalue`/`min_identity` under `by: "structure"`, `ticket_id`/a non-empty `databases` under `by: "sequence"` — under a new `mode_mismatched_field` reason, instead of silently dropping it ([#57](https://github.com/cyanheads/protein-mcp-server/issues/57)).
- **`protein_get_annotations`** rejects a missing identifier or a malformed `uniprot` accession as `InvalidParams` (`missing_identifier`/`invalid_accession`), instead of `NotFound`/`no_uniprot_mapping` ([#46](https://github.com/cyanheads/protein-mcp-server/issues/46)).

## Fixed

- **`RcsbService.graphql()`** throws on a non-empty `errors` array even when `data` is also present, instead of returning the partial payload as an ordinary sparse record ([#48](https://github.com/cyanheads/protein-mcp-server/issues/48)).
- **`protein_track_ligands`** (`mode: find_ligand`) routes a formula-shaped `query` (spaced or unspaced Hill notation) through RCSB's `chemical`/`formula` terminal instead of the name/synonym search, falling back to the name search when the formula terminal matches nothing ([#50](https://github.com/cyanheads/protein-mcp-server/issues/50)).
- **`protein_get_structure`**'s text surface no longer truncates inlined coordinates to a 2,000-character prefix — a structure under the response budget renders whole, one over it gets the same withheld marker the batch-overflow gate already renders ([#59](https://github.com/cyanheads/protein-mcp-server/issues/59)).
