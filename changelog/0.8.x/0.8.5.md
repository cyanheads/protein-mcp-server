# 0.8.5 — 2026-09-22

## Added

- **`protein_track_ligands` `binding_site`** — pocket residues now carry author numbering (`authAsymId`/`authSeqId`) beside the mmCIF label numbering (`asymId`/`seqId`), and the ligand instance reports its own author chain and residue number (#69).

## Fixed

- **`protein_track_ligands` `find_ligand`** — responses report `totalCount` and `candidatesConsidered`, with a `notice` when a broad name's matches exceed the ranked candidate pool (#67).
- **`protein_track_ligands` `binding_site`** — ligand instances now page with `start`/`limit`, gaining `totalCount`/`nextStart` and a past-end `notice` (#75).
