# 0.5.1 — 2026-08-16

## Added

- **`protein_analyze_collection` `bucketsReturned`**: new required enrichment field reporting the realized bucket total summed across every dimension level — the size a cross-tab returns isn't legible from `bucket_limit` alone ([#36](https://github.com/cyanheads/protein-mcp-server/issues/36)).

## Changed

- **`bucket_limit` semantics**: the input description, the tool description, `PROTEIN_FACET_BUCKET_CAP`'s config description, and the README now state that the cap applies per dimension level, not per response — a cross-tab can return up to `bucket_limit × (1 + bucket_limit)` buckets ([#36](https://github.com/cyanheads/protein-mcp-server/issues/36)).
